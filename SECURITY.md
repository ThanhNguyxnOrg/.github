# 🔐 Security Policy

Thanks for helping keep ThanhNguyxn's projects safer.

---

## 📌 Scope

This workspace contains a mix of:

- active projects
- experiments
- rebuilds of older work
- archived references

Because of that, security support may vary between repositories.

---

## 🚨 Reporting a vulnerability

If you discover a security issue:

- for sensitive reports, open a private security advisory: https://github.com/ThanhNguyxnOrg/.github/security/advisories/new
- please avoid publishing exploit details immediately
- provide a clear summary of the issue
- mention the affected repository
- explain possible impact
- include safe reproduction steps if necessary

---

## 🧠 Good report format

A useful report should include:

- repository name
- affected file/module
- severity estimate
- reproduction details
- suggested fix if available

---

## ⏳ Response expectations

Since this is a personal workspace:

- response time may vary
- actively maintained repos will be prioritized
- archived repos may not receive immediate fixes

---

## ✅ Responsible disclosure

Please act in good faith and allow reasonable time for review before public disclosure.

Thanks for helping improve project safety ✨
