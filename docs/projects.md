# 📚 Projects Overview

This document explains the kinds of repositories that may appear in **ThanhNguyxn-Org**.

---

## 🧪 Experiments
Small builds, tests, proof-of-concepts, and idea exploration.

These repos may be:
- incomplete
- unstable
- fast-moving
- intentionally lightweight

---

## 💻 Applications
More serious projects such as:
- websites
- tools
- systems
- backend services
- full applications

---

## 🛠️ Utilities
Developer helpers like:
- CLI tools
- scripts
- automation
- reusable setups
- workflow boosters

---

## 📘 Learning Repositories
Projects created to understand concepts better.

These might include:
- practice implementations
- concept demos
- topic-based exercises
- architecture exploration

---

## ♻️ Rebuilt / Migrated Repositories
A special category in this organization.

These repos may represent:
- restored work
- updated rewrites
- cleaned-up versions
- migrated projects from older accounts

---

## 🗃️ Archive
Some repositories are preserved mainly for:
- reference
- history
- progress tracking
- old experiments worth remembering

---

## 🌟 Maturity levels
Projects here may be in different stages:

- idea
- prototype
- active development
- stable
- archived

That variation is intentional.
