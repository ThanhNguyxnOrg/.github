# 🤝 Contributing

Thanks for your interest in contributing to **ThanhNguyxn-Org**.

This organization is primarily a **personal GitHub workspace**, so contribution rules may differ across repositories.

---

## 🌟 Before you contribute

Please try to:

- read the repository README first 📖
- check open issues before creating a new one 🔎
- keep pull requests small and focused ✂️
- explain clearly **what changed** and **why** 🧠
- update docs if your change affects setup or usage 📝

---

## 🧪 Important context

Some repositories in this organization are:

- experiments
- learning projects
- rebuilt legacy repos
- archived references
- active long-term builds

That means not every repo will accept large outside contributions.

---

## ✅ Best contribution style

The best contributions usually look like:

- fixing bugs 🐛
- improving documentation 📚
- cleaning code structure 🧹
- suggesting better approaches 💡
- reporting reproducible issues 🛠️

---

## 🚫 Please avoid

- huge PRs with unrelated changes
- low-context issues
- style-only rewrites with no clear benefit
- breaking existing structure without discussion

---

## 💬 Communication

If you're unsure whether something is worth contributing:

1. open an issue first
2. describe the idea simply
3. explain why it helps
4. wait for alignment before major work

---

## 💖 Final note

Even though this is a personal organization, thoughtful contributions are always appreciated.

Thanks for stopping by and helping make things better ✨
