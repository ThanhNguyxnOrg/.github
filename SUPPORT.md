# 🆘 Support

Need help with a repository in ThanhNguyxn's workspace?
Open an issue in the relevant repository with clear context.

---

## 🔎 Before opening an issue

Please check:

- the repository `README.md`
- setup instructions
- existing issues
- docs inside the repository
- release / update notes if available

A lot of common setup problems are already answered there.

---

## 📨 Best way to get help

Open an issue in the relevant repository and include:

- what you're trying to do
- what actually happened
- what you expected
- screenshots or logs
- environment details if needed

The clearer the report, the easier it is to help.

---

## ⚠️ Support expectations

This is a **personal workspace**, so support is provided on a:

### ⭐ best-effort basis

That means:

- response time may vary
- some repos may be inactive
- some repos are experimental by design
- some archived repos may not receive further updates

| Status | Examples | Expectation |
|---|---|---|
| Active | blendops, lumeo, apidex-hub, SkillGauge | Issues reviewed, fixes prioritized |
| Maintained | PurgeKit, Locsight, cogmint, ForgeHelm | Best effort, slower responses |
| Reference / archive | Older snapshots as labeled | May not receive updates |

---

## 🛠️ For bug reports

Please include:

- OS / environment
- steps to reproduce
- exact error output
- relevant screenshots
- repository version / commit if known
